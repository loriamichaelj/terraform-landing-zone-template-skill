# Getting help

| Need | Where |
| --- | --- |
| Questions about using or designing the skill | [Discussions → Q&A](https://github.com/loriamichaelj/terraform-landing-zone-template-skill/discussions/categories/q-a) |
| Ideas and early proposals | [Discussions → Ideas](https://github.com/loriamichaelj/terraform-landing-zone-template-skill/discussions/categories/ideas) |
| Something is broken | [Open a bug report](https://github.com/loriamichaelj/terraform-landing-zone-template-skill/issues/new/choose) |
| A security problem | Report it privately, as described in [SECURITY.md](SECURITY.md) |

Before asking, check [docs/DESIGN.md](docs/DESIGN.md), [docs/ADR.md](docs/ADR.md) and the [runbooks](docs/runbooks/). Many answers, and the open questions, are there.

This is a volunteer-maintained project; there's no paid support or response-time guarantee. When you share specs or logs, redact org IDs, billing accounts, CIDR plans and email addresses.
